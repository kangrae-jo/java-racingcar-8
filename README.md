# Woowa-precourse 2주차

## 용어 정의

### 자동차

| 용어           | 설명                        |
|--------------|---------------------------|
| Car          | 게임에서 전진하거나 멈추는 행동을 하는 자동차 |
| Car Name     | 자동차에 부여되는 이름              |
| Car Position | 자동차의 현재 위치                |

### 자동차 이동 상태

| 용어      | 설명   |
|---------|------|
| Forward | 앞 방향 |
| Stop    | 멈춤   |

### 횟수

| 용어    | 설명              |
|-------|-----------------|
| Round | 경주가 진행되는 횟수의 단위 |

### 숫자

| 용어            | 설명                       |
|---------------|--------------------------|
| Random Number | 0~9 사이 무작위 값             |
| Threshold     | 4의 값으로, 전진과 멈춤을 구분하는 임계값 |

### 우승

| 용어     | 설명                            |
|--------|-------------------------------|
| Winner | 가장 많이 전진한 Car에 부여된 이름 (복수 가능) |

## 기능 요구 사항

- [ ] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
    - `Car`는 매 `Round`에 `Forward` or `Stop` 상태를 가진다.
- [x] 각 자동차에 이름을 부여할 수 있다.
    - `Car`는 `Car Name`을 가진다.
- [ ] 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
    - `Car`는 `Forward`상태일 때 `Car Name`을 출력한다.
- [ ] 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
    - `Car Name`들은 쉼표를 기준으로 구분한다.
    - `Car Name`은 5자 이하이다.
- [ ] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
    - 사용자는 최대 `Round`를 입력으로 지정할 수 있다.
- [ ] 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
    - `Forward`조건은 `Random Number`가 `Threshold`이상의 값을 가질 때 이다.
- [ ] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
    - 자동차 경주 게임을 완료하면 `Winner`를 출력한다.
    - `Winner`는 한 명 이상이다.
- [ ] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
    - `Winner`가 여러명일 경우 쉼표로 구분한다.
- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.
